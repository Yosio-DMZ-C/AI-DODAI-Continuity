00初回認証がまだの場合

AD&Cからチャットで非公開投稿するには、初回だけGoogle Cloud・Cloudflareの接続設定が必要です。 画面変更に備え、実施時にはAD&Cが公式資料を再検索して簡単な手順を案内します。

初回設定の短い手順を表示（約6工程・認証情報の送信禁止）
  1. Google Cloud Consoleでプロジェクトを選び、YouTube Data API v3 と Google Drive APIを有効にします。
  2. Google Auth Platformのブランディング・対象ユーザーを設定し、テスト状態なら自分のGoogleアカウントをテストユーザーへ追加します。
  3. Clientsから「デスクトップアプリ」のOAuthクライアントを作り、JSONをPCへダウンロードします。セキュリティ上、ダウンロードしたOAuth JSONをチャットへ送信・添付してはいけません。認証情報を含む画面の共有も避けてください。
  4. CloudflareでWorkerとKVを用意し、配布ZIPのwrangler.toml.exampleをwrangler.tomlにコピー、期待するチャンネルID・KV IDを設定します。
  5. PCでZIPのsetup_once.pyを実行し、Googleの同意画面で承認します。接続先チャンネルを照合してから秘密情報をWorkerへ登録します。
  6. 生成された個人用プラグインをChatGPTに接続し、check_connectionで検査した後、非公開投稿を試します。

Google OAuthのテスト状態では更新トークンが約7日で期限切れになる場合があります。継続運用前に公開ステータスや審査要件を確認してください。

わからないところは教えてください。現在の画面に合わせて案内します。

手順書：配布ZIP内INITIAL_AUTH_GUIDE.md。Webブラウザからの一時認証だけなら下の「01」で進められますが、チャット自動投稿には別途初回サーバー設定が必要です。
