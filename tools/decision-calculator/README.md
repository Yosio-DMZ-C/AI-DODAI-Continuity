# AgentOS-C 計算尺 v0.1（試作・独立ツール）

Life Skillsの「数値検証」だけを外部計算へ逃がす小型の検算ツールです。KB本体、共有知、推論ルール、回答の口調は変更しません。

**用途は、住宅購入時の現金収支と住宅ローンの元利均等返済の検算に限定**しています。科学的根拠や法律、現行金利、購入の適否を判定する機能はありません。

## 使い方

### 人がブラウザで検算する場合

このフォルダの **index.html** と **calculator.js** を同じ場所に保存し、index.html をブラウザで開きます。ブラウザ内だけで動作します。外部ライブラリ、サーバー、ログインは不要です。結果のJSONをコピーしてAIへ渡すこともできます。

> GitHubのファイル閲覧画面ではHTMLのJavaScriptは実行されません。GitHub Pagesの公開設定も、この試作では行っていません。ブラウザで使うには2ファイルを保存してください。

### コマンド実行可能なAIの場合

Node.js 18以上が利用できる環境で、同じフォルダのファイルを用いて実行します。依存パッケージのインストールは不要です。

    node tools/decision-calculator/calculator.js tools/decision-calculator/example.json

または、JSONを標準入力から渡します。

    node tools/decision-calculator/calculator.js -

入力キー（単位に注意）：

| キー | 意味 |
|---|---|
| purchase_price_man_yen | 物件価格・万円の整数 |
| savings_man_yen | 利用可能な貯蓄・万円の整数 |
| down_payment_man_yen | 頭金・万円の整数 |
| closing_costs_man_yen | 諸費用・万円の整数 |
| minimum_reserve_man_yen | 残したい現金・万円の整数 |
| annual_interest_rate_percent | **仮定**する年率％（例：1.0） |
| loan_term_years | 返済年数（整数） |

example.json は、貯蓄900万円、頭金700万円、諸費用300万円、希望予備資金300万円の過去テストです。期待値：

- 購入時の現金残高：**−100万円**
- 初期費用を支払うための不足額：**100万円**
- 予備資金300万円を残すための不足額：**400万円**
- 諸費用300万円と予備資金300万円を維持する場合の頭金上限：**300万円**
- その場合の借入額：**3,500万円**
- 3,100万円、年率1.0％、35年の元利均等返済：**約87,509円／月**

金額入力は万円の整数とし、返済額は円で返します。ローン試算は金利が返済期間中一定と仮定した概算です。

## AI利用時の短い手順

1. 回答の判断を左右する金額があるか確認する。
2. 利用可能な計算ツールがあれば数値を入力し、**実際の計算結果**を読む。ツールにアクセスできない場合は実行したと主張しない。
3. 元の提案と検算結果を照合し、不一致の箇所だけ修正する。
4. 「計算が正しいこと」と「前提の金利・相場・制度が正しいこと」、「本人に適した選択であること」は分ける。
5. 数値が不要な質問や簡単な会話では、このツールを呼ぶ必要はない。

このツールはAIのツール呼び出し機能に自動接続されません。ツール実行可能なAIだけがCLIを実行できます。実行機能がないAIにはブラウザから得たJSONを渡します。

## 品質ゲート

    node --test tools/decision-calculator/test.cjs

検査項目：現金不足と予備資金の不足、修正後の頭金上限、年利0％、金利変化、境界値、不正入力、CLIと関数結果の一致、ブラウザ画面で同じ計算ロジックを使用していること。

**実行した検査の結果がPASSと確認できるまでは試作品として扱います。** テストが通っても、金利・法制度の正確性や実運用環境での操作成功を保証しません。

## 境界と将来

- 生の計算処理だけを実装。住宅ローン審査や税制・修繕費を推定しない。
- 計算結果は検算材料であり、「買うべき」などの推薦を出さない。
- まずはT1の再現性を確認。需要が増えるまでは汎用数式パーサーや自動Web連携を作らない。
- 他のAIや計算手段への差し替えは自由。GitHub Pages等の配信設定は別途判断する。
