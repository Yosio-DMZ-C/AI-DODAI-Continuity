# AD&C 実行時・軽量品質指示パイロット v0.1

- 状態：**DRAFT／設計と試験素材の作成。ChatGPTの設定変更は未実施**
- 目的：AIの思考手順を縛らず、利用者の操作負担につながる出力漏れを減らす
- 正本の根拠：[共通実行標準 §6.3](../PROJECT_EXECUTION_STANDARD.md)。この文書は短い「実行時の入口」であり、正本の複製や置換ではない
- 対象：AD&Cの開発・調査・成果物・引き渡し。通常の雑談や無関係の作業へ無条件適用しない

## 1. 実行時に渡す短い指示（貼り付けるのは枠内だけ）

```text
【AD&C実行時の軽量品質指示／試験版】
AD&Cの仕事では、人間が迷わず次の操作をできることを重視する。AIの推論手順や用途に合った表現方法は固定しない。
・共有・引き渡し：判断に必要な所見も成果物に含め、【引き渡し】【依頼事項】【確認状況】を一組にする。人がコピーする必要があれば、対応UIでは全文を一操作でコピーできる明示ボタンを付け、非対応ならコピーしやすいテキストを用意する。未確認のコピー成功を主張しない。
・GUI案内：閲覧なら対象、アップロード・置換なら作業先フォルダなど、実際に操作を始められる画面と一般的な操作を優先する。
・ダウンロード提供するWindows用PS1：実行方法とともに、配布元の確認、ファイルのプロパティで［許可する］が表示された場合の解除手順を添える。組織ポリシーの一律回避は案内しない。
同じ用途の表示・コピー方式は原則維持する。回答直前に該当項目だけ点検し、未実施・未検証はそのまま明示する。
```

**出口の軽量判定**：回答を出す直前に、依頼に該当する項目だけ「受け手が迷わず実行できるか／重要情報と必要な操作がそろうか」を確認する。常時チェックリスト全文を表示したり、雑談に不要なUIを強制したりしない。リンク・コピー操作は表示できた事実と実際に利用成功した事実を別々に扱う。

## 2. 指示を「配信」する方法と限界

**2026-10-16 試験運用判断：当面は独立チャットを維持する。** 他AI・無料環境で再現する自然な利用上のつまずきを観測するため、ChatGPTプロジェクトへの一斉移動やグローバル指示への一括登録を先行しない。これは標準化の断念ではなく、実環境評価のための観測条件である。

- **通常の独立チャット（観測群）**：追加の短文指示を強制せず、自然な利用で発生した操作負荷・脱落・UI問題を記録する。モデルの記憶や過去文脈にルールが入っている場合は「純粋な無指示」と表現しない。
- **検証を行う個別チャット（介入群）**：必要なケースでだけ上記の短文指示を貼り付け、指示の有無と注入時点を記録して比較する。試験用ケースは機密を除き、モデル・プラン・端末・チャット履歴の差を記録する。
- **プロジェクト機能・カスタム指示**：将来の比較候補として保留。広域適用は別途明示判断とし、一般ユーザー・無料環境・他AIでの再現性を確認せず共通の前提にしない。
- **GitHub上に保存しただけでは適用されない**。今回の独立チャット試験では、対象チャットへ短い指示を実際に手動投入したことを確認した場合だけ`injected=yes`とする。プロジェクト／カスタム指示欄の変更は本試験では実施せず、設定済み・投入済みと推定しない。
- 他AIでは各サービスの指示・プロジェクト機能に応じて同じ短文を渡す。各サービスでの保持・遵守は別途検証。

## 3. 試験ゲート

1. **配布**：独立チャットで指示なし／指示ありを区別し、手動指示を渡した場合は投入文と時点を確認する。プロジェクト／グローバル設定への登録は本試験で必須としない。
2. **静的出力**：共有の本文完結性・コピー対象・GUI開始画面・PS1事前準備・同用途UI継承を、該当ケースだけ判定。
3. **実画面**：コピー操作がレンダリングされるか。表示PASSだけで実コピーPASSにしない。
4. **利用結果**：実クリックによるクリップボード内容の完全性、上書き後のファイル内容などは、本人または実機試験の証拠がある場合だけPASS。
5. **負荷／副作用**：余計な手順、無関係なボタン、冗長化、未確認の成功宣言を記録。

[試験課題20件と採点方法](../evaluations/RUNTIME_OUTPUT_PILOT_CASES_v0.1.md)を使う。**設定済み・検査済み・効果実証済み**を混同しない。

## 4. 中止・撤回

利用者が違和感を報告したとき、または操作性が悪化したときは、追加した試験文だけを設定欄から外して前の状態へ戻す。GitHubの正本と既存の他設定は保持する。評価前に不要な自動化・リリース・全チャットへの一斉移行はしない。
