# 過去の記録：2026-10-09時点

> この文書は提供元の機能保証ではなく、今回までの限定的な試験と公式公開資料を区別した記録です。AIのモデル、契約、実行ツール、添付UIは変更され得ます。試験で「成功」と報告された部分と第三者が独立に確かめた部分を混同しません。

## 現在の開発優先度

1. **無料・制限環境：KB構築と外部バックアップを基本とする。** AIが利用者の提供資料から文書・索引を構築し、取得可能な形で渡す。人間がPC・スマホ・非公開クラウド保存先へ保管する。
2. **直接接続が確認できた環境：** KBへの直接書込・再読取・必要箇所の更新を個別に検証する。
3. **継続更新・AI間の移植：** 「別チャットのAIが元のKBを読み、同じNodeIDと記録を保ったまま動けるか」を独立テストしてから対応を表明する。Memory、共有リンク、前チャットのCookieを必須条件にしない。
4. Core Life Skillsは別の未実装構想。本体導入を阻害しない。

## 無料・制限環境での成果物

- **第一候補：** `AgentOS-C_initial.zip`、元ファイルを含む完全版の初期KB。
- **ZIPを生成・配布できない場合：** 全相対パス・各ファイル全文・NodeID・構築状態を含み、機械的に再構成できる単一Markdown/TXT。単に目次や要約を集めたものは全件バックアップと呼ばない。
- **結果に不完全な部分がある場合：** 元資料の未取得部分や欠落を明示し、完全バックアップのPASSを出さない。
- **既存KBを別AIへ渡すとき：** 受け取り側で入力ファイルを実際に読み、NodeIDと必須ファイル、件数と参照、未確認状態を照合する。移植は**これから実証する機能**。
- **人間の作業：** 出力成果物を自分の保存先へ保存するだけ。バックアップ先の更新ができるとは推測しない。

## 最小品質ゲート

- 必須の入口 `START_HERE.md`、`BUILD_PLAN.md`、`00_system/registry.json` がある。
- 実際に出力したファイルを読戻し、NodeID、全文・件数・参照、ZIPなら解凍・CRC等を確認する。
- `購入していない` は `所有していない` を証明しない。所有・在庫の未確認は unknown/unconfirmed と記録する。
- 最新版の入口が登録済みKnowledgeを「空」と誤記しない。
- 旧版と更新版を区別し、更新テスト中に元のバックアップを上書きしない。
- 新規チャットで読めない場合は中断し、「継続同期の成功」としない。
- 必須ゲートに `FAIL`・`NOT_RUN` が残る成果物を完成と称さない。
