## 実証の開示基準

完全にPASSしていない機能を「導入できる」と保証しない。AIが「完了」と報告しても、実物の存在・JSON・参照・ファイル形式を独立確認する。未実施項目はNOT_RUNと記載する。

## PR投稿文の方向性（編集用）

**軸：** 「AIを乗り換えても、自分の知識は残る。」

**補足：** AgentOS-Cは新しいAIではなく、自分の情報をAIの外で管理し、必要時に引き継ぐための仕組み。無料・制限環境でも最小限のKB構築とバックアップを狙い、AIによる受渡しの実動作を公開検証中。成功も失敗も隠さず記録していく。

**誘導先：** GitHub README → `docs/wiki/Home.md` → Quick Start → 設計書。
