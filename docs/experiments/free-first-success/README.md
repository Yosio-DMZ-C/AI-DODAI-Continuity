# 無料・未連携でも、次のチャットで再開

使うものは、普段のチャットAIとスマホ／PCのメモ帳だけ。アカウント連携、有料機能、自動化、コード実行は不要です。この例の[買い物リスト](shopping-list.md)は架空データです。

## 1. リストを手元に保存する

このページの [shopping-list.md](shopping-list.md) を開き、本文をコピーします。スマホのメモアプリなら、タイトルを「買い物リスト」にして本文を貼り付けて保存するだけでも構いません（`.md` ファイルを作る機能は不要）。PCなどでテキストファイルとして保存できる場合は **shopping-list.md** と名付けます。いずれも一度閉じて開き直し、本文が残っていることを確認してください。

公開デモのURLをAIに見せるだけでも試せますが、個人の買い物リストや個人情報は公開リポジトリに保存しないでください。自分用の内容は手元の非公開ファイルに書きます。

## 2. 新しいチャットで続きを確かめる

新しいチャットを開き、ファイル保存した場合は **shopping-list.md** を添付します。スマホのメモアプリに保存した場合や添付機能がない場合は、保存済みメモを開いて**本文全体をコピーし、新しいチャットへ貼り付けてから**次を送ります。保存したメモをAIが自動で見つけることはありません。

> 添付した買い物リストだけを読んで、購入済みと未購入を分けて。ファイルの内容が読めなければ推測せず、ファイル添付か全文貼り付けを1回だけ案内して。

添付できないときは、メモ帳でファイルを開き、全文をコピーしてチャットに貼り付けてから同じ依頼を送ってください。無料版の機能や添付上限は環境によって変わることがあります。

**この例の答え：** 購入済み＝冷凍ごぼう／未購入＝冷凍ブルーベリー、玉ねぎ。新しいチャットが実際にファイル本文を受け取り、この分類を答えたときだけ再開できたと確認します。

品目を変更したら、AIの返答だけで保存済みと思わず、手元の **shopping-list.md** を編集して保存してください。
