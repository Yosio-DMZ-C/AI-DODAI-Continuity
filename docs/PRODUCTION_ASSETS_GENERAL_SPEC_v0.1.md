# 制作素材 一般仕様表 v0.1（2026-10-25）

> **対象**：解説・PR動画向けの再利用可能な制作素材セット。AD&C固有の制作指示・インストール必須物ではない。**画像・動画・PPT制作を希望する場合に限り**、現在の作品で必要な素材を特定するために使用する。

**出典と検証状態**：2026-10-25に利用者が提示した「制作素材 一般仕様表 v0.1」の項目・使いどころ・状態を一般仕様とプロジェクトの記録に分離して保全したもの。右端の「AD&Cの状態」は**提出時の自己申告／整理結果**であり、リーダーが全原本を独立取得して検証した結果ではない。現行の採用や所有を証明しない。別プロジェクトでは自分の状態に差し替える。

**使い方（KB構築時の任意工程）**：
1. [共通実行標準 §6.3.2](PROJECT_EXECUTION_STANDARD.md)に従い、作業Runbook冒頭の**「必要資料・素材・ツール」**一か所から採用素材へ到達する。
2. この表は**候補の分類表**。8種類のロゴ・すべての人物ポーズ・約40点のアイコンを最初から全件生成する義務ではない。実制作に必要なものだけ、既存の原本・権利・採用状態を確認して採用する。使わないカテゴリは理由付きN/A。
3. 同じ仕事で比較・選択する画像が2枚以上なら、番号・素材ID・採用状態が分かる**一つのコンタクトシート／視覚一覧**を用意する。視覚一覧は閲覧用で、個別画像原本・透過・編集可能なデータを置き換えない。
4. 既存の`30_contexts/Areas`（シリーズ基準）・`30_contexts/Projects`（案件採用／残件）・registryの**実ID・版・権利・原本所在**を利用。表の「あり／使用中／定義済み」は、当該ファイルを実取得して使えることとは別。未取得はNOT_RUN、不足を勝手なロゴ生成・似た素材で補わない。
5. 未整備や最終承認待ちは既存のTASKS／Project／Issueの当該タスクに残し、文書に「完成」と書いただけでDONEへ変えない。

## 表B：人物素材

役割は作品ごとに読み替える（進行役／共感役＝視聴者の代弁／解説役＝専門家、など）。

### B-1 バストアップ（常用ポーズ）

| パターン | どの役でも要るか | 使いどころ | AD&Cの状態（提出時点） |
|---|---|---|---|
| 案内（手を差し出す・通常笑顔） | 進行役 | 汎用、導入、OP | あり |
| 困った（頭をかく等） | 全役 | できなかった系、正直検証 | 私のみ追加済み |
| 怒った・指摘（腕組み等） | 進行・解説役 | 問題指摘、注意喚起 | 私のみ追加済み |
| 考え込む | 全役 | 比較検討、判断 | 私のみ |
| 驚き | 全役 | 想定外の結果、速報 | 不足 |
| 納得・うなずき | 共感役中心 | 締め、共感の着地点 | ワタシのみ（提出文の表記を維持。誰の素材か別途照合） |
| 疑問（首かしげ） | 共感役 | 質問の導入 | 近いカットあり |
| 端末を見せる・見る | 進行・共感役 | 実演の導入 | 不足 |
| 解説（指差し・手元に資料やPC） | 解説役 | 根拠の提示 | あり |
| 真剣な視線 | 解説役 | リスク警告、例外説明 | 不足 |
| 掛け合い（2人） | 組み合わせ | 対話形式 | 個別素材から合成 |

### B-3 小物（人物とセットで使う物）

| 小物 | 備考 | AD&Cの状態（提出時点） |
|---|---|---|

| ノートPC | 解説役の主端末。開いた状態と半開き | 専門家ボード内に描写あり |
| タブレット | 大きく見せる実演用 | 未整備 |
| マイク | 収録・肉声の象徴として | 未整備 |

### B-4 人物素材の技術仕様（一般）

- 背景は単色に寄せ、切り抜き・合成ができること
- バストアップは短辺1,200px級以上（サムネイルで大きく扱えること）
- 画風・線の質感・色調は全役で統一
- 視線のバリエーション（カメラ目線／斜め／横顔）を最低限そろえる
- 全身図は原則作らない（立ち絵が要る媒体がある場合のみ例外）
- 背景付きの場面絵は作らない（場面は都度合成・生成）

ここでの寸法・ポーズは**対象媒体に合わせて適用する一般目標**。ユーザーが作らないと決めた人物役や媒体への生成を強制しない。正式採用には見本・縮小時の可読性・本人が判断する範囲の承認を別途確認する。

## 必須の検収（該当制作に限る）

| ゲート | PASS条件 | 失敗・未実施の扱い |
|---|---|---|
| A/B/C/Dの**適用範囲の選択** | 今回の作品に必要な種類と不要な種類が、正式な案件判断に沿っている | 未決定は候補で保留。「表にあるから全て必須」にしない |
| 原本と採用判断 | 現行版・本人承認・権利・実体IDを各必須素材に紐付けて実取得 | 旧ロゴや類似生成で無断代用しない |
| 複数画像の見落とし防止 | 一覧のID／件数が原本群・Runbookと一致。縮小時にも判読可能 | 不一致FAIL、未取得NOT_RUN。見た目の一覧だけでPASSにしない |
| ツールやSVGの使用 | 実ファイルの取得、必要環境での表示／実行を確認 | 配布予定や「定義済み」だけではNOT_RUN |
| 受渡し | Runbook冒頭から必要なファイル・本人判断・未完了へ到達 | 他AIの独立Q2／実制作Q3は試験がなければNOT_RUN |
