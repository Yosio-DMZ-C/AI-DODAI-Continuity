# AD&Cを試す｜はじめての方へ

> **AIを替えても、冒険は続く。**

今使っているAIに、**あなたの好みや作業の続きを残す「土台」**を作ってもらう、実験的なプロジェクトです。端末に実行プログラムをインストールしたり、Gitを操作したりする必要はありません。AIに渡すMarkdownインストーラーを使います。

## まず、これだけ

**[① AD&Cインストーラーを取得する（現行・単一版／Markdown）](../AgentOS-C_設計・構築運用指示書_一般配布版.md)**

**②** 取得したファイルを、普段使っているAIのチャットに添付する。

**③** チャットで **`実行`** と送る。あとはAIの案内に従い、保存先を選び、提案を確認して **`進めて`** と送る。

**MuseでのQR利用例（2026-10-25、利用者報告）**：現行AD&Cインストーラーを指すQRコードから案内を開き、Museへその内容を示して **`これを実行して`** と依頼する方法でも、導入作業を進められた。QRの参照先は上記①と**同じ単一インストーラー**であり、別の「Muse版」を配布しているわけではない。**QRを読み込むだけでインストールが完了するという意味ではない。** AIが実際に設計書を読めたか、保存先の選択・接続許可・実ファイル保存と読戻しを工程ごとに確認する。他のAI／端末／Museの別環境で同様に進められるかは未検証。QRやページの内容をAIが読み取れない場合は②のファイル添付か全文貼り付けへ戻す。

<small>ファイル名に旧称 `AgentOS-C` が含まれますが、現行AD&Cのインストーラーです。**以前の「AI無課金ユーザー版 v1.2.1」などの旧ファイルは新規導入テストに使わず、必ず上の単一リンクから現行本文を取得**してください。無料／有料ではなく、選んだ保存先へ実際に読書きできるかでモードを決めます。</small>

**使える範囲はAI・契約・端末によって異なります。** まずはAIが作成したファイルを受け取って、自分の非公開の保存先へ保管するところまで試してください。チャットを替えた後の自動復元や更新は、まだ環境ごとの検証が必要です。

うまくいかないとき：**[ファイルの取得・添付方法（端末別）](Upload-File.md)** ／ **[実動作の検証結果](Verified-Results.md)**

**すでにKBを使っている方**：新規インストールは繰り返さず、[アップデート専用入口](../updates/UPDATE.md)を使用してください。版が不明な旧KBは同手順から[互換導入](../updates/ADOPT_LEGACY.md)へ分岐します。元ファイルとIDを保持し、明示承認前に更新しません。

## もう少し詳しい手順

### 1. 取得してAIへ渡す

**基本**：上の単一インストーラーを保存し、AIのチャットにファイルとして添付します。**リンクをAIへ送るだけでは、内容を読めるとは限りません。** 添付できない場合は、設計書の本文をコピーして送る方法もあります。

**Museで試せた別の入口（利用者報告）**：同じインストーラーへのQRを読み取り、開いた導入案内をMuseに渡して `これを実行して` と依頼する。Museが文書本文を取得・解釈できた場合は、従来と同じ保存先選択以降の流れで進める。具体的なQR読取画面やAIへの渡し方は利用環境に依存するため、再現できない場合は基本のファイル添付へ戻す。

### 2. `実行` → 保存先を選ぶ → `進めて`

`実行` を送ると、AIが保存先を質問し、最初に作る内容を提案します。内容を確認し、問題なければ `進めて` と送ります。追加情報が必要な場合だけ回答してください。

### 3. 作られたファイルを保存・確認する

ファイル添付中心のAIでは、`AgentOS-C_initial.zip` などの成果物を受け取り、**実際に開けること**を確認して、PC・スマホ・Google Drive・個人用OneDriveなど自分で管理する非公開の保存先に保管します。ZIPに未対応なら、復元できるMarkdown/TXTで代替できる場合があります。

AIが保存先へ直接書き込める場合は、フォルダと主要ファイルが本当に作られているか確認します。**AIが「できた」と回答しただけでは保存完了ではありません。**

### 4. 次のチャットで続ける

保存した最新版のZIPなどを新しいチャットへ添付して試します。再読込・更新ができる範囲はAI環境によって異なります。**元のバックアップを残して検証**してください。

## 動画・PPTを作る人の初期設定（希望時のみ）

導入時に「動画制作の初期設定もしたい」と伝えた場合、AIは**保存先の確定と`進めて`の後で**採用済みのPPTX、ロゴ、サムネイル、色、OP等を確認し、本人の非公開KBの既存Area/Project Contextへ素材の参照と制作設定を保存します。元のPPTXを渡せる場合は、**画像を真似て新しく作る前に見本PPTをコピー・再利用**することが基本です。詳しい手順は[共有KBのPPT動画制作Skill（Draft）](https://github.com/Yosio-DMZ-C/AD-C-Shared-Knowledge/blob/main/skills/video-production-setup/SKILL.md)にあります。非公開の素材は共有GitHubへ公開しません。

希望しない人には、動画用フォルダ、PPTや録音サービスを追加しません。**既にKBがある場合は再インストールせず[更新入口](../updates/UPDATE.md)を使います。** 作成した制作設定が別チャットで実際に再取得できるかは、別途試験が必要です。

## 保存先によってインストーラーが動作を切り替えます

同じインストーラーから、AIが選択先への**実際の読書き可否**を確認します。直接読み書きできればクラウド連携モード、できなければZIPまたはMarkdown/TXTを本人が保存するローカル手動保存モードです。**無料／有料やAIの種類で別ファイルを選ぶ必要はありません。**

## 技術情報・安全性・ご協力

AD&Cは開発・検証中です。個人の会話や会社の機密を公開GitHubへ送らず、保存先の権限を確認してください。通常の試用に検証レポートの提出は必要ありません。
