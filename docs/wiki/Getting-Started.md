# 最初に試す — AgentOS-C導入

[概要へ戻る](Home.md) | [実証結果](Verified-Results.md)

## 1. AIの能力で導入方法を選ぶ

料金プランではなく、**現在使っているAIが外部保存先のファイルを実際に読み書きできるか**で選びます。

| 利用環境 | 使う設計書 | 初回の目標 |
|---|---|---|
| 保存先への直接読書きが実測済み | [一般配布版](https://github.com/Yosio-DMZ-C/AgentOS-C/blob/main/docs/AgentOS-C_設計・構築運用指示書_一般配布版.md) | 展開Workspaceの構築・読戻し |
| 添付ファイル中心、または直接書込が未確認 | [AI無課金ユーザー版](https://github.com/Yosio-DMZ-C/AgentOS-C/blob/main/docs/AgentOS-C_設計・構築運用指示書_AI無課金ユーザー版.md) | KBの構築・ZIP等での受渡し・手動保存 |

Markdown原本を保存したい場合は、それぞれのGitHubファイルページから **Raw** を開き、テキストとして保存してください。ブラウザや端末により操作名は異なります。

## 2. AIに渡す入力

設計書をAIのチャットへ添付、または本文を貼り付けます。続けて：

```text
実行
```

AIが保存先を尋ねたら回答し、提示された初回案を確認してから：

```text
進めて
```

## 3. 受渡しとバックアップ

1. 実ファイルの `AgentOS-C_initial.zip`（または復元可能な完全Markdown/TXT）を取得します。
2. ZIPなら展開できるか、`START_HERE.md`、`BUILD_PLAN.md`、`00_system/registry.json` が含まれるか確認します。
3. Google Drive、個人用OneDrive、PC/スマホ内の**非公開**フォルダへ原本を保管します。
4. 保管後に再読込できた場合だけ「外部バックアップを確認」と記録します。

AIの完了報告だけでは実ファイルの存在・構文・ID整合性が保証されません。**ダウンロードリンクが表示されず、ファイルも実在しない場合は受渡し未完了**です。ZIPが出ない環境では、完全な代替テキストを求めます。

## 4. 別チャット・別AIへ引き継ぐ

これは**発展機能・要実証**です。最新版の完全ZIP等を新規チャットに渡し、NodeID、ファイル件数、参照先、再開位置を照合します。更新は、検査が済むまで旧ZIPを残し、新しい完全版として出力するのが安全です。

## 注意

- 実際の個人KB・機密文書を公開GitHubへアップロードしないでください。
- AIのMemory、クラウド接続、自動同期、他AI間移植を必須の能力として想定しません。
- 各AIのテスト結果は[実証状況](Verified-Results.md)を参照してください。
