# AgentOS-Cを試してみる

[概要](Home.md) ／ [実動作の検証結果](Verified-Results.md)

AgentOS-Cを始めるときに必要なのは、利用するAIと、知識ベースを保存する場所です。

## 1. 設計書を選ぶ

| 利用するAIの環境 | 選ぶ設計書 |
|---|---|
| AIからGoogle Driveなどへ**直接読み書きできることを確認済み** | [一般配布版](../AgentOS-C_設計・構築運用指示書_一般配布版.md) |
| ファイルの添付・ダウンロードが中心、または直接接続できるか分からない | [AI無課金ユーザー版](../AgentOS-C_設計・構築運用指示書_AI無課金ユーザー版.md) |

迷う場合は、**AI無課金ユーザー版**から試す方法が簡単です。名称にかかわらず、有料AIでも直接保存できない環境では利用できます。

リンク先のMarkdownファイルを開き、GitHubの `Raw` 表示などから保存して、AIのチャットに添付してください。添付できない場合は本文を貼り付ける方法もあります。

## 2. チャットで構築を始める

設計書を渡したら、次の一言を送ります。

```text
実行
```

AIが保存先を質問し、初回の作成内容を提案します。内容に問題がなければ次を送ります。

```text
進めて
```

あとはAIの案内に従います。追加情報が必要な場合だけ回答してください。

## 3. 作成したKBを保存する

**ファイル添付中心のAIの場合：**

1. AIから `AgentOS-C_initial.zip` を受け取ります。ZIPが扱えない環境では、全ファイルを再現できるMarkdown/TXTを使います。
2. ファイルを実際に開けることを確認します。
3. 自分のPC・スマホ、Google Drive、個人用OneDriveなどの**非公開の保存先**に保管します。

**保存先に直接読み書きできるAIの場合：**

AIが作成したフォルダと主要ファイルが、指定した保存先に存在するか確認します。

作成に失敗したり、ダウンロードできるファイルが表示されなかったりした場合は、その画面やエラーメッセージをAIへ伝えてください。作り直しではなく、足りない部分を確認するところから始められます。

## 4. 次のチャットでも使いたいとき

保存した最新版のZIPなどを、新しいチャットへ添付して読み込ませます。**新しいチャットで実際に読み込めるか、更新したファイルを再び受け取れるか**は、利用するAIごとに確認が必要です。まずは元のバックアップを残して試してください。
