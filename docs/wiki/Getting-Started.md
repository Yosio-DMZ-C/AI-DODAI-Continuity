# AD&Cを試す｜はじめての方へ

> **AIを替えても、冒険は続く。**

今使っているAIに、**あなたの好みや作業の続きを残す「土台」**を作ってもらう、実験的なプロジェクトです。端末に実行プログラムをインストールしたり、Gitを操作したりする必要はありません。AIに渡すMarkdownインストーラーを使います。

## まず、これだけ：写真を送る

[![AD&C共通インストーラーのQR画像](../../assets/adnc-installer-qr.png)](https://raw.githubusercontent.com/Yosio-DMZ-C/AI-DODAI-Continuity/main/docs/AgentOS-C_%E8%A8%AD%E8%A8%88%E3%83%BB%E6%A7%8B%E7%AF%89%E9%81%8B%E7%94%A8%E6%8C%87%E7%A4%BA%E6%9B%B8_%E4%B8%80%E8%88%AC%E9%85%8D%E5%B8%83%E7%89%88.md)

1. [QR画像を保存する](../../assets/adnc-installer-qr.png)。
2. いつものAIに**写真として送って、「これを実行して」**と伝える。
3. AIが[現行の共通インストーラーMarkdown本文](https://raw.githubusercontent.com/Yosio-DMZ-C/AI-DODAI-Continuity/main/docs/AgentOS-C_%E8%A8%AD%E8%A8%88%E3%83%BB%E6%A7%8B%E7%AF%89%E9%81%8B%E7%94%A8%E6%8C%87%E7%A4%BA%E6%9B%B8_%E4%B8%80%E8%88%AC%E9%85%8D%E5%B8%83%E7%89%88.md)を取得できたら、保存先を選ぶ。作成案を確認して `進めて` と伝え、**実ファイルの保存・読戻し**まで確認する。

**QR画像を読み取っただけで導入が終わるわけではありません。** QRの文字列解読、正式MD本文の取得と配布版確認、接続確認、保存、読戻しを区別します。2026-11-01のMuse試験ではGitHubリンクを404とする報告や、類似文書への誘導がありました。QRでの導入を全AIで実証したわけではありません。

QRの読み取りや本文取得ができないときは、[同じ単一インストーラー](../AgentOS-C_設計・構築運用指示書_一般配布版.md)をMarkdownファイルとして添付し、`実行` と送ります。[ファイルを送る方法](Upload-File.md)。

**以前の「AI無課金ユーザー版」は過去の保全資料**であり、新規導入では選びません。無料／有料・AIの種類で別インストーラーを使い分けず、保存先への実際の読書き能力で動作が分かれます。ファイル名に残る `AgentOS-C` は旧称・互換表記です。

## もう少し詳しい手順

### 1. QR画像を送る（第一候補）

スマホの写真を送れるAIへ、上のQR画像を送って `これを実行して` と伝えます。画像を解読できてもリンク先を取得できない場合があります。**正式なMarkdown本文を開いたか**をAIに確認させます。

失敗時は[現行Markdownをファイル添付する方法](Upload-File.md)へ切り替えます。GitHubページのプレビューや404になった類似文書だけで導入を続けません。

### 2. 本文取得 → 保存先選択 → `進めて`

QR画像方式は `これを実行して` が導入依頼です。ファイル添付方式では `実行` と送ります。正式本文が取得できたら、AIが保存先を質問し、最初に作る内容を提案します。内容を確認し、問題なければ `進めて` と送ります。追加情報が必要な場合だけ回答してください。

### 3. 作られたファイルを保存・確認する

ファイル添付中心のAIでは、`AgentOS-C_initial.zip` などの成果物を受け取り、**実際に開けること**を確認して、PC・スマホ・Google Drive・個人用OneDriveなど自分で管理する非公開の保存先に保管します。ZIPに未対応なら、復元できるMarkdown/TXTで代替できる場合があります。

AIが保存先へ直接書き込める場合は、フォルダと主要ファイルが本当に作られているか確認します。**AIが「できた」と回答しただけでは保存完了ではありません。**

### 4. 次のチャットで続ける

保存した最新版のZIPなどを新しいチャットへ添付して試します。再読込・更新ができる範囲はAI環境によって異なります。**元のバックアップを残して検証**してください。

## 動画・PPTを作る人の初期設定（希望時のみ）

導入時に「動画制作の初期設定もしたい」と伝えた場合、AIは**保存先の確定と`進めて`の後で**採用済みのPPTX、ロゴ、サムネイル、色、OP等を確認し、本人の非公開KBの既存Area/Project Contextへ素材の参照と制作設定を保存します。元のPPTXを渡せる場合は、**画像を真似て新しく作る前に見本PPTをコピー・再利用**することが基本です。詳しい手順は[共有KBのPPT動画制作Skill（Draft）](https://github.com/Yosio-DMZ-C/AD-C-Shared-Knowledge/blob/main/skills/video-production-setup/SKILL.md)にあります。非公開の素材は共有GitHubへ公開しません。

希望しない人には、動画用フォルダ、PPTや録音サービスを追加しません。**既にKBがある場合は再インストールせず[更新入口](../updates/UPDATE.md)を使います。** 作成した制作設定が別チャットで実際に再取得できるかは、別途試験が必要です。

## 保存先によってインストーラーが動作を切り替えます

同じインストーラーから、AIが選択先への**実際の読書き可否**を確認します。直接読み書きできればクラウド連携モード、できなければZIPまたはMarkdown/TXTを本人が保存するローカル手動保存モードです。**無料／有料やAIの種類で別ファイルを選ぶ必要はありません。**

## 技術情報・安全性・ご協力

AD&Cは開発・検証中です。個人の会話や会社の機密を公開GitHubへ送らず、保存先の権限を確認してください。通常の試用に検証レポートの提出は必要ありません。
