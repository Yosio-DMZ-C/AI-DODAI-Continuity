# AD&Cを試す｜はじめての方へ

> **AIを替えても、冒険は続く。**

今使っているAIに、**あなたの好みや作業の続きを残す「土台」**を作ってもらう、実験的なプロジェクトです。特別なアプリのインストールやGit操作は必要ありません。

## まず、これだけ

**[① 導入用ファイルをダウンロードする（基本版・Markdown）](https://github.com/Yosio-DMZ-C/AI-DODAI-Continuity/releases/download/guides-current/AgentOS-C_Free_Guide.md)**

**②** 取得したファイルを、普段使っているAIのチャットに添付する。

**③** チャットで **`実行`** と送る。あとはAIの案内に従い、保存先を選び、提案を確認して **`進めて`** と送る。

<small>ファイル名に旧称 `AgentOS-C` が含まれますが、AD&Cの互換用配布ファイルです。</small>

**使える範囲はAI・契約・端末によって異なります。** まずはAIが作成したファイルを受け取って、自分の非公開の保存先へ保管するところまで試してください。チャットを替えた後の自動復元や更新は、まだ環境ごとの検証が必要です。

うまくいかないとき：**[ファイルの取得・添付方法（端末別）](Upload-File.md)** ／ **[実動作の検証結果](Verified-Results.md)**

## もう少し詳しい手順

### 1. 取得してAIへ渡す

上の基本版を保存し、AIのチャットにファイルとして添付します。**リンクをAIへ送るだけでは、内容を読めるとは限りません。** 添付できない場合は、設計書の本文をコピーして送る方法もあります。

### 2. `実行` → 保存先を選ぶ → `進めて`

`実行` を送ると、AIが保存先を質問し、最初に作る内容を提案します。内容を確認し、問題なければ `進めて` と送ります。追加情報が必要な場合だけ回答してください。

### 3. 作られたファイルを保存・確認する

ファイル添付中心のAIでは、`AgentOS-C_initial.zip` などの成果物を受け取り、**実際に開けること**を確認して、PC・スマホ・Google Drive・個人用OneDriveなど自分で管理する非公開の保存先に保管します。ZIPに未対応なら、復元できるMarkdown/TXTで代替できる場合があります。

AIが保存先へ直接書き込める場合は、フォルダと主要ファイルが本当に作られているか確認します。**AIが「できた」と回答しただけでは保存完了ではありません。**

### 4. 次のチャットで続ける

保存した最新版のZIPなどを新しいチャットへ添付して試します。再読込・更新ができる範囲はAI環境によって異なります。**元のバックアップを残して検証**してください。

## クラウドへ直接保存できるAIをご利用の方

利用中のAIがGoogle Drive等へ**実際に読み書きできると確認済み**なら、[クラウド連携用ガイド（一般配布版）](https://github.com/Yosio-DMZ-C/AI-DODAI-Continuity/releases/download/guides-current/AgentOS-C_Guide.md)も選べます。単にクラウドのアカウントを持っているだけでは直接接続できるとは限りません。

## 技術情報・安全性・ご協力

AD&Cは開発・検証中です。個人の会話や会社の機密を公開GitHubへ送らず、保存先の権限を確認してください。通常の試用に検証レポートの提出は必要ありません。
