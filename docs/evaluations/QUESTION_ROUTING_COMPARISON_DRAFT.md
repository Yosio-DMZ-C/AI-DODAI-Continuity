# AD&C 質問処理方式 比較評価ケース（Draft）

- 作成日：2026-10-15（JST）
- 対象：一般配布設計書 §12・§14 の Retrieval / Aggregate / Temporal / Synthesis
- 状態：**試験設計。実AI・実サービスでの比較実行は NOT_RUN**
- 前提：すべて架空の小さなデータ。個人KB、実ユーザー情報、外部DBは不要。**受験AIへ渡すのは以下の「AI入力」欄だけ**。期待値・FAIL例・未取得資料の真値は評価者のみ参照する。
- 優先順位：Foundation（構築・保存・読戻し・更新・復元）を優先。代表4問で評価方法を確認後、20問の比較実行は別工程で判断する。

## 0. 入力と採点情報の分離（評価実施時の必須条件）

- **受験AI向け**：各ケースの「AI入力：架空資料・質問」列だけを渡す。同じ資料と質問を旧方式・改定方式に与える。評価者専用の期待値・FAIL条件・隠された資料は提供しない。
- **評価者専用**：その他の「期待結果」「FAIL例」、およびQ07の未取得ページP2の真の3件は採点時だけ参照する。未取得資料の内容からAIが全件を答えた場合は情報漏れを疑い、比較データとして扱わない。
- Q07の**受験AIに見せる固定レスポンス**：`page=P1; records=[E1,E2,E3,E4]; next_page_token=P2`。P2の取得は失敗し、総件数メタデータは無い。質問：「全体では何件ありますか？」。このレスポンスはP2の件数を含まない。
- Q07の**評価者専用の真値**：P2にはE5、E6、E7が存在し、全件は7件。ただし受験AIがP2を取得できない条件では、確認済み4件の部分集計と全件不明という回答を正答とする。

## 1. 比較方法と品質ゲート

比較するのは「現行の質問処理手順」と「§12の型別処理原則を使った手順」。**同じAI・同じモデル設定・同じデータ・同じ権限・同じ質問**を使い、実行順やキャッシュの影響を記録する。モデル変更やデータ補充を改善効果と混同しない。

各ケースで質問型（複合型なら処理順序）・使用した原資料ID・対象全体の定義・除外・重複処理・回答対象時点・取得数／未取得数・回答・実行時間・ツール呼出数を記録する。環境が返さない負荷値は `NOT_RUN` とし推測しない。

|ゲート|PASS|FAIL|NOT_RUN|
|---|---|---|---|
|R：根拠と回答|必要な出典と本文が一致し、断定の強さが根拠に合う|出典が無い、検索上位だけを全体と誤認、資料の意味を誤る|回答未実行|
|A：集計|母集団・除外・重複・計算規則と対象範囲を示し、確定値が再計算可能|母集団不明や取得漏れを隠して全件確定を主張、誤算|回答未実行|
|T：時間|出来事・有効時点・記録時点を質問の要求に沿って区別|日付の捏造、古い決定と現在の決定の混同|回答未実行|
|S：分析範囲|評価対象と未取得部分を明示し、結論が調査範囲内|部分資料を全体の結論として断定|回答未実行|
|L：負荷|実測の所要時間・ツール呼出数等を記録（値の優劣は別途比較）|計測値を推測で確定記入|測定機能・実行なし|

**部分回答は許容**：対象ページ等の一部しか取得できない場合、取得した対象だけを示す「部分集計」「限定評価」はPASS可能。全件確定と表現した時だけFAIL。検索ヒット数を無条件に母集団の件数と扱わない。単一質問で不要なゲートは理由付き N/A とする。

## 2. 代表4問：評価方法の先行確認（設計レビュー用）

以下4問を先に確認する。各行の期待結果と失敗条件が再現できることを**机上で確認**する工程と、AIが実際に正しく回答するかの**実行試験**は分ける。

|ID・型|AI入力：架空資料・質問（受験AIに渡す列）|評価者専用：期待結果・検査方法|評価者専用：FAIL例|
|---|---|---|---|
|Q01 Retrieval|資料 R1「Kerberos障害では再試行間隔2秒」、R2「プロキシ初期化」。質問「Kerberosの再試行間隔は？」|R1を提示し「2秒」と回答。根拠R1を示す。R2だけでの推定不可|R2だけを引用、根拠なしで3秒と回答|
|Q06 Aggregate|4行：E1=100、E2=50、E2の重複コピー=50、E3=20。質問「イベント総額は？」（同一IDは一度だけ）|母集団4行、ユニーク3件、合計170と説明|重複を足して220と確定|
|Q11 Temporal|決定 D1 は1/10から有効、D2 は2/12から有効、D2の記録日は2/14。質問「いつ方針がD2に変わった？」|有効変更日2/12、記録日は2/14と区別|2/14を変更日と断定|
|Q16 Synthesis|評価資料 S1=肯定、S2=肯定、S3=否定、評価対象はこの3件。質問「全体として全員一致？」|対象3/3確認、肯定2・否定1なので「全員一致ではない」|「全員肯定」と結論|

**代表4問の方法レビュー**：4分類のルーティング先、期待値、必要根拠、FAIL条件は記載済み。実AIへの現行方式／新方式の2系統投入と負荷計測は未実施であり、実行性能をPASSとしない。
