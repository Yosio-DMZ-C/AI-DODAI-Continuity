# 無料AIとスマホメモで続きから使う｜AD&C継続キット

このページでは、初めての人は架空の買い物リストで保存と再開を試せます。すでに続けている作業があれば、前のチャットで決めたことをスマホのメモに保存し、新しいチャットへ自分で渡して再開できます。

必要なのは、インターネットに接続できるスマートフォン、利用できる無料AIの通常チャット、スマホのメモアプリ、コピー＆ペーストです。AIの無料プランには利用回数やファイル機能の制限がある場合があります。AIそのものへのアクセスは必要です。

**これは自分でコピーして保存する、無接続の手動ルートです。** クラウド連携、GitHub、APIキー、有料契約、AIによる自動保存は必要ありません。新しいチャットが前のチャットやスマホのメモを自動で読めるとは限りません。保存した文章を自分で新しいチャットへ貼り付けます。

> 最初は実際の個人情報ではなく、下の架空の買い物リストで試してください。個人情報、パスワード、秘密の業務情報を公開ページや共有先へ貼らないでください。

## 最短5操作（まずここから）

1. [手順1](#1-保存する継続パケット)の架空パケット全文をスマホのメモにコピーする。
2. メモを閉じて開き直し、保存した本文を確認する。
3. 新しい無料AIチャットを開く。
4. メモ本文と[手順4](#4-新しいチャットで再開する)の依頼文を一緒に貼り付けて送る。
5. AIが目的・現在の状態・次の1作業を正しく言い直したか確認する。

**この5操作は手動で行います。** AIがスマホのメモを自動保存・自動取得するわけではありません。以下の手順1〜6に詳しい説明があります。

## 1. 保存する継続パケット

次のひな形全体をスマホのメモにコピーします。例の買い物リストは架空です。自分の作業に合わせて必要な行だけ書き換えてください。

```text
【AD&C継続パケット】
案件名：買い物リストの例
更新日時：2026-11-05 18:00（自分の現地時刻）

■目的
買うものと、買ったものを次のチャットでも確認できるようにする。

■現在の状態
未購入：
- 冷凍ブルーベリー
- 玉ねぎ

購入済み：
- 冷凍ごぼう

■決定したこと
- これは動作確認用の架空データ。
- 買った品目は「購入済み」へ移す。

■次にすること（1件）
- 買い物の後、買った品目を購入済みに移して、このメモを更新する。

■保存場所
スマホのメモアプリ「AD&C継続キットのテスト」

■再開時の注意
- この文章が最新か、更新日時を確認する。
- 書かれていないことは推測しない。
- 新しいチャットには、この文章を自分で貼り付ける。
```

## 2. 前のチャットで最新版を作る（初回の架空テストなら省略）

**初めて試す場合・引き継ぐ前のチャットがない場合は、手順1の架空パケットをそのまま使い、手順3へ進んでください。** 前のチャットがなくても無料キットの保存→新チャット再開を試せます。

すでに続けていた作業がある場合だけ、そのチャットを開いて次の文を送ります。手順1のページをAIが読めなくても項目を落とさないよう、依頼文に継続パケットの項目名を含めています。

```text
このチャットの最新状態を【AD&C継続パケット】として、次の項目名を付けて出力して：案件名／更新日時／目的／現在の状態／決定したこと／次にすること（1件）／保存場所／再開時の注意。決定事項と未完了を分け、次にすることは1件に絞って。会話から確認できないことや現在日時・保存場所が不明なら推測せず「未確認」と書いて。個人情報や秘密情報は入れないで。私は内容を確認し、更新日時と保存場所を実際の値に直してからスマホのメモへコピーして保存します。
```

AIの回答をざっと確認します。事実と違う内容や、不要な個人情報があれば、メモに保存する前に直してください。AIが保存したとは見なさず、次の操作は自分で行います。

## 3. スマホのメモへ保存して開き直す

**初回の架空テストでは手順1の継続パケット全体をコピーします。** すでに前のチャットで作業している場合は、手順2で確認したAIの回答から継続パケット全体をコピーします。スマホのメモアプリでテスト用メモを新規作成または更新します。保存したあと、そのメモをいったん閉じてもう一度開き、最新日時と本文が残っていることを確認します。

古い内容を残したい場合は、上書き前に複製するか、古い版を別のメモに移してください。保存したつもりでも開き直して確認できなければ、保存完了とは扱いません。

## 4. 新しいチャットで再開する

新しいチャットを開き、スマホのメモから最新版の継続パケットをコピーして貼り付けます。その下に次の依頼文を加えて送ります。

```text
以下は自分でメモに保存して持ってきた継続パケットです。まず内容を読み、目的・決定事項・現在の状態・次にする1作業を短く確認してください。そのあと、次の1作業から手伝ってください。パケットに書かれていないことは前の会話の記憶で補わず、必要なら質問してください。実行や保存ができたと確認できない場合は、完了したと言わず、私が行う操作を1つ示してください。
```

**新しいチャットにはパケット本文も一緒に貼ります。** この公開ページのURLだけを送っても、あなたの個人メモや前の会話は読み込まれません。ファイル添付が使えない無料AIでも、本文をコピーして貼れば再開を試せます。

## 5. 最新版への更新と復旧

新しいチャットで作業が進んだら、**いま作業しているチャット**に「このチャットで進んだ内容を反映し、継続パケットを最新版に更新して」と頼みます。更新内容を確認してから、スマホのメモ本文を置き換え、閉じて開き直してください。必要なら置き換える前に古い版を複製します。メモの更新は自分で行います。

新しいチャットで再開できないときは、次を順に確認します。

1. メモアプリで最新版の継続パケットを開けるか確認する。
2. パケット本文を省略せず、新しいチャットへ貼り直す。
3. AIに「受け取った本文の目的と次の1作業を言い直して」と頼む。
4. それでも読めない場合は、メモの内容を確認し、本文をもう一度コピーする。前のチャットの返事だけを根拠に内容を作り足さない。

メモが見つからない、本文が欠けている、最新版か判断できない場合は、「未保存」または「未確認」として扱います。分からない状態から勝手に再構成しないでください。

## 6. このキットでできること・できないこと

- **できること：** 自分で文章をメモに保存し、次のチャットへコピーして渡す。
- **できないこと：** AIがメモを自動更新すること、次のチャットが前のチャットやメモを自動で発見すること。
- **必要なもの：** AIとインターネットへのアクセス。無料プランの利用回数や機能はサービスによって異なります。
- **確認の基準：** メモを開き直して本文を確認すること。さらに新しいチャットが貼り付けた内容を読み取り、目的と次の作業を正しく言い直したこと。
- **位置づけ：** これはユーザー自身のコピーと保存で成立する、低機能・無接続の基礎ルートです。AD&CのクラウドKB自動書込や正本整合契約とは別の方法です。

この手順の設計を示したもので、実際のスマホや無料AIアカウントでの操作・別チャット間の実利用試験を済ませたという意味ではありません。実際に試すまでは、利用者による実利用検証は **NOT_RUN** です。
