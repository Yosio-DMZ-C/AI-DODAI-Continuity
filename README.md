# AgentOS-C

> **AIを乗り換えても、自分の知識は残る。**

AgentOS-Cは、調べたこと、判断した理由、作業手順、次にやることを、**AIサービスの外に保存して再利用するためのオープンな仕組み**です。

AIと長く作業していると、別のチャットに移るたびに前提を説明したり、以前の判断を探し直したりすることがあります。AgentOS-Cは、知識と作業状態を自分が管理するファイルに残し、必要に応じてAIに渡せる形を目指しています。

新しいAIモデルではありません。Markdown、クラウドストレージ、既存のAI機能などを組み合わせる運用方法です。

## まず試す：3ステップ

1. [導入ガイド](docs/wiki/Getting-Started.md)を開き、自分の環境に合う設計書をAIへ渡す。
2. チャットで `実行` と送り、AIが示す保存先と作成案を確認する。
3. `進めて` と送る。作成された知識ベース（KB）を受け取り、自分の保存先に保管する。

**迷ったらファイル添付中心の方法から試せます。** 直接クラウドへ書き込めるAI環境では、別の方法も選べます。

[**はじめての方へ**](docs/wiki/Home.md) ／ [**Quick Start**](QUICKSTART.md)

## どんなことができる？

- **知識の引き継ぎ：** 資料や判断の経緯をまとめ、説明のやり直しを減らす。
- **作業の再開：** 完了した作業と未完了の作業を残し、続きから取り組みやすくする。
- **ファイルの管理：** AIのチャットだけに依存せず、PCやクラウドで知識を保管する。

最初に実現するのは、**KBの作成と外部へのバックアップ**です。別チャットからの読込みや継続的な更新は、AI環境ごとに検証を進めています。

## 自分のAIに合う導入方法

**クラウドへの直接読み書きを確認できたら：** [一般配布版](docs/AgentOS-C_設計・構築運用指示書_一般配布版.md)で、保存先にKBのファイルを作成します。

**添付ファイル中心、または接続可否が不明なら：** [AI無課金ユーザー版](docs/AgentOS-C_設計・構築運用指示書_AI無課金ユーザー版.md)で、ZIPなどを受け取り、自分で保存します。

設計書はAIへの作業指示を含むMarkdownファイルです。「AI無課金ユーザー版」は、無料プラン専用という意味ではありません。

[実動作の検証結果](docs/wiki/Verified-Results.md)では、Claude・Gemini・Grokなどで試した内容を紹介しています。利用できる機能はAIサービスや接続環境によって異なります。

## 中身は普通のファイル

AgentOS-Cでは、主に次のようなファイルを使います。

| ファイル・フォルダ | 役割 |
|---|---|
| `START_HERE.md` | AIが最初に読む、KBの入口 |
| `BUILD_PLAN.md` | 作業の進行状況と次の手順 |
| `00_system/registry.json` | ファイルや記録を探すための管理情報 |
| `20_knowledge/`・`30_contexts/` | 整理した知識と用途別の引き継ぎ情報 |

最初からすべてのフォルダを用意する必要はありません。必要な範囲から始められます。

## この先に広がる使い方

個人の知識管理に加えて、次のような活用も構想しています。

- **組織標準KB：** 企業・NPOの規程や申請書を、実際の仕事の場面で案内する。
- **インストーラKB：** 保存環境の準備や、組織文書からのKB作成を対話形式で手伝う。
- **共有知：** 主張・根拠・反論を整理し、調査にかかる時間を減らす。
- **Core Life Skills：** 健康、契約、防災など、重要な場面の初動を支援する。

これらは**今後の構想・開発テーマ**です。[詳しい構想を見る](docs/wiki/Future-Vision.md)
