# AgentOS-C v0.1.0

**歴史的なv0.1.0の配布スナップショット（保全資料）**です。**新規導入の入口ではありません**。現行の正本は[共通AD&Cインストーラー1本](../docs/AgentOS-C_設計・構築運用指示書_一般配布版.md)で、[QR画像から始める方法](../QUICKSTART.md)もあります。

この `release/` ディレクトリには、現在READMEとmanifestを置いています。実際の配布ZIPは、設計書・QUICKSTART・README・LICENSE・manifestをまとめた搬送用スナップショットとして扱います。

## 使い方

**現在の新規導入では旧版を選択しません。** 以下は古い配布方式の説明（歴史記録）です。当時の配布文書を渡した場合は次の指示が使われました。

```text
実行
```

AIが保存先と実際の読書き能力を確認し、

- 実際に直接読書き可能と確認できた場合のみ展開Workspace
- 直接読書き不可の場合は**KB構築＋外部バックアップ**（可能ならZIP、不可なら復元可能な単一Markdown/TXT）
- その後のZIP往復更新・AI間移植は別途実機テストに成功した環境だけの拡張

のどちらかで構築します。

旧「AI無課金ユーザー版」という名称は当時の制約環境向けの設計名で、現在は**料金にかかわらず共通版1本から保存先の実能力で分岐**します。**初回ZIPの生成・取得をすべての無料AIに保証するものではありません。** 本リポジトリにあるv0.1.0のmanifestと旧SHA-256は過去の配布スナップショットを指し、本説明更新に合わせて新しい配布ZIPを作成したわけではありません。
